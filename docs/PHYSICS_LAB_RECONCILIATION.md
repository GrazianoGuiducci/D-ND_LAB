## Distribution and installation

This repository already ships `domains/physics/config.json` and its domain
inputs. The engine loader resolves `domains/<domain>/config.json`. The
standalone dnd-lab-physics repository instead retains its historical input at
`domain/config.json`; cloning the complete repository directly to
`domains/physics` introduces an extra directory level and does not match the
loader contract.

Use the domain shipped here for this engine. Any experiment with the separate
historical package belongs in a disposable installation with a validated
domain layout, not an overwrite of a live physics domain. See the companion's
[compatibility guide](https://github.com/GrazianoGuiducci/dnd-lab-physics/blob/main/docs/DND_LAB_COMPATIBILITY.md).

The existing May bootstrap and experiment scripts remain unchanged. Their
historical acceptance and falsifier receipts are evidence of those specific

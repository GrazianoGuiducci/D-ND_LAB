# Physics domain for the D-ND_LAB engine

This is the physics domain shipped with the installable engine. It includes
its config, context, seed tensions, assertions, category map, experiment tools
and the dated `bootstrap_20260516/` reinstall snapshot. It is not a placeholder.

The current **regenerative** Physics Lab is developed independently in MM-DND
and exposed at [d-nd.com/ai-lab](https://d-nd.com/ai-lab). Its
[public companion](https://github.com/GrazianoGuiducci/dnd-lab-physics) provides
the current explanation and offline corpus reader. Running this engine does
not reproduce that private operational implementation.

For this domain's configuration and historical scope, read
[the physics guide](../../docs/domains/physics.md). The
[distribution reconciliation](../../docs/PHYSICS_LAB_RECONCILIATION.md) explains
the shared genealogy, correct installation layout and preserved evidence.
